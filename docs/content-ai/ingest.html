content-ai-ingest

One function — runFill — populates an entity's fields from an external source in a single model call. Use it when content arrives from outside the entity: a PDF, image, pasted text, a URL, or a sibling-locale entity to translate from.

When to reach for it

  • Importing a recipe from a scanned PDF or a photo of a label.
  • Seeding a draft entity from pasted text or a source URL.
  • Translating an entity into a new locale (a SiblingLocaleSource).

If instead you want to generate or improve a field from data already on the entity, use runRefine.

The IngestContract

An IngestContract is the source-driven analogue of an AiContract: a Zod schema, a systemPrompt, and a buildMessages that turns your source context into model input (plain prompt or multimodal message parts). Optional fieldPolicies / fieldConfigs set per-field write and translation behavior. 

import type { IngestContract, MessageSet } from "@pixelmord/content-ai-ingest";

const recipeIngest: IngestContract<typeof recipeSchema, RecipeSource> = {
  schema: recipeSchema,
  systemPrompt: "Extract a structured recipe from the supplied source.",
  buildMessages: async (src): Promise<MessageSet> =>
    src.kind === "pdf-vision"
      ? { messages: [{ role: "user", content: [{ type: "file", data: src.bytes, mediaType: "application/pdf" }] }] }
      : { prompt: src.content },
  fieldPolicies: { title: "fill-if-empty" },
};

runFill is side-effect free. It returns suggestions and autoApplied (both keyed by field), per-call traces, any warnings from message-building (e.g. a truncated PDF), and an ingestedEvent for you to persist to the entity's event log.

Reading the result

import { runFill } from "@pixelmord/content-ai-ingest";

const result = await runFill({ contract: recipeIngest, sourceContext, config });

// Collapse single-valued suggestions into a draft fields record:
const fields: Record<string, unknown> = {};
for (const [field, s] of result.suggestions) {
  if (s.kind === "single") fields[field] = s.value;
}

// Persist provenance (your I/O — the runner never writes):
await eventLog.append(entityRef, result.ingestedEvent);

Translation is a source kind

A SiblingLocaleSource carries the source-locale entity, the target locale, and per-field hashes. Pass mergeInstruction (or the exported MERGE_INSTRUCTION) to blend new translation into existing target-language text rather than overwriting editor changes. runRefine deliberately rejects sibling-locale sources — translation always goes through runFill.
