content-ai-core

The shared substrate every runner builds on: the contract vocabulary, the AI event log, fingerprinting, the provider factory with tracing, and presentation helpers. You rarely call core directly — you author types it defines and read results it shapes.

Core concepts

AiContract — the object you author

A contract pairs a Zod schema with per-field AI behavior. Each FieldConfig says how to prompt (systemPrompt), what JSON to ask for (outputSchema), whether a result may auto-apply (autoApply), how it interacts with an existing value (writePolicy), and how it behaves under translation. A systemPrompt that returns "" gates the field off — that is how preconditions like “no inventory ⇒ no pairings” are expressed. 

import type { AiContract } from "@pixelmord/content-ai-core";

const recipeContract: AiContract<typeof recipeSchema> = {
  schema: recipeSchema,
  presets: [expandPreset, summarizePreset],
  fields: {
    description: {
      systemPrompt: (ctx) => `Write a description for ${ctx.currentData?.name}.`,
      autoApply: { policy: "high-confidence", threshold: 1.0 },
      writePolicy: "fill-if-empty",
    },
    pairings: {
      bulk: true, // attempted on every full refresh
      systemPrompt: (ctx) =>
        ctx.sourceContext?.inventory.length ? PAIRING_PROMPT : "", // gated
    },
  },
};

Event log & suppression

AiEventLog is an append-only history per entity (EntityRef). Core stamps id and at. rejected and ingested events are never pruned — the former drives suppression (a re-proposed identical suggestion is filtered by fingerprint), the latter records source attribution (ADR 0004 / 0012).

isSuppressed · filterSuggestions · buildRejectedContext · recordAiEvent

Fingerprinting

fingerprintHash normalizes a value (trim/lowercase strings, sort keys, recurse arrays) then takes a short SHA-256. Cosmetically different values hash identically — the basis for dedup and suppression. hashContent gives a full-length hash for per-field staleness diffing.

fingerprintHash · hashContent · diffFieldHashes

Provider & tracing /server

createProvider(config, { sinks }) builds the language model. With sinks, it wraps the model in tracingMiddleware so every call emits a TraceEvent tagged with the ambient Origin (carried via async-local storage). Set AI_PROVIDER=mock for the synthesizing e2e model.

createProvider · resolveConfig · wrapWithOrigin · TraceSink

Translation & refresh classification

TranslationBehavior declares per-field translate / copy / localize / skip. classifyRefreshKind reads those modes against a set of stale fields: all-copy ⇒ silent, otherwise review-required (ADR 0015).

resolveTranslation · classifyRefreshKind
