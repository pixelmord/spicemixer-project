Initial release of the `content-ai-*` package family as `0.1.0`.

- `@pixelmord/content-ai-core`: AI contract types, event log interface, trace sink, Origin/ALS, fingerprinting, suppression rules, and presentation helpers.
- `@pixelmord/content-ai-refine`: `runRefine` contract-driven per-field AI refine runner.
- `@pixelmord/content-ai-ingest`: `runFill` source-context typed AI fill runner.

Published to GitHub Packages (`https://npm.pkg.github.com`) under scope `@pixelmord`. Pre-1.0; no deprecation contract owed.
